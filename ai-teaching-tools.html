AI Teaching Tools & Resources

Training and Teaching

  • Google AI for Social Good — Training on the machine learning (ML) fundamentals and applications.
  • Google PAIR AI Explorables — Small modules on different AI topics.
  • fast.ai Data Ethics — Course on the various ethical implications of data and ML.
  • AI Hall of Shame — Wired database of AI-related incidents.
  • AI Incident Database — Database of AI-related incidents.
  • Neural Networks Playground — Different exercises to train and engage with a neural network.
  • Neural Networks and Deep Learning — Open access textbook.
  • Google Machine Learning Crash Course — A free course on machine learning.
  • TowardsAI — Media publication.

Demonstration Sites

NLP

  • Word2Viz — Word embeddings exploration tool.
  • Word2Vec Demo — Word embeddings exploration tool.
  • IBM Watson Natural Language Understanding Text Analysis — More complex natural-language-powered text analysis demo.
  • Gender Decoder — Trained to identify gendered language in job postings.

Computer Vision

  • COCO Explorer — Labeled image dataset.
  • Open Images Dataset — Labeled image dataset.
  • Google Cloud Vision API — Test the system by dragging and dropping an image for analysis.
  • MyHeritage — Animate still photos.
  • Flim — AI-assisted film still search.

Generative AI

  • ChatGPT — Created by OpenAI, this application makes text generation more accessible. It should be noted that it feels like a knowledge bank when it answers questions, but the text is generated through a predictive algorithm that crafts the text using statistics to guess the most likely next word in the answer.
  • BlenderBot — Meta's text generator demoed as a chat bot.
  • DALL-E — This image generation application creates a visual using a text prompt. Try the same prompt with different art styles.
  • TryItOn — Takes an image you provide to generate a range of machine-learning-generated headshots.

Training

  • Teachable Machine — Train an ML categorization tool without coding.
  • Do Not Touch Your Face — Train a tool to teach yourself not to touch your face (made during the start of the coronavirus pandemic).
  • Survival of the Best Fit — Game to demonstrate AI bias in hiring.

Other

  • ClipDrop by Stable Diffusion — Uses AI to edit images or generate new images from a sample image.
  • DeepAI Colorizer — API to use AI to colorize black-and-white pictures.
  • LALAL.AI — Extract vocals and instrumentals from audio tracks.
  • Moral Machine — Explore the decisions about which lives to save that an automated vehicle may need to make while driving.

Interesting AI-Related Tools to Explore

  • Syntho — AI software for generating synthetic data.
  • Designs.AI — AI-generated graphic media.
  • scite — Citation analyzer to see how an article was cited (think citator for scientific articles).
  • Eyewire — Crowdsourcing neuron mapping to inform research and AI analysis.
  • The Polite Library — Social media filter tool, on a mission to slow down the pace of the internet and opt out of a world dominated by artificial intelligence.
  • GitHub Copilot — Programming code autocomplete product.
  • Wizdom.ai — Research intelligence tool.
  • Iris.AI — AI tool to assist with literature review and other research efforts.
  • diffeo — Research assistance tool.
  • Metomic.io — AI tool to identify possible security risks in unstructured data.
  • LOIO — Legal contract review tool.

Other Emerging Tech

  • Blockchain Explained — Visual representation by Reuters of how blockchain functions.
  • Blockchain Demo — Cloud-hosted demo of blockchain.
